Create your account on the Pi

ReefBerry is installed but has no account yet. For security, the first account can only be created on the Pi itself, so nobody else on your network can claim this dashboard.

Connect to the Pi (SSH or Raspberry Pi Connect) and run:

sudo reefberry user add

Then reload this page and sign in.

Forgot your password later? Run sudo reefberry user reset-password on the Pi.
